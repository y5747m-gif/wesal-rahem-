# وصال ❤️ (WESAL)

> **لا تجعل الانشغال يجعلك تنسى من تحب.**

تطبيق عربي أولًا (RTL) يساعد المستخدم على الحفاظ على صلة الرحم والاطمئنان على أقاربه
بانتظام، عبر جدول أسبوعي بسيط، وتذكيرات إنسانية، وتحقق اختياري، وتصعيد عائلي هادئ
وآمن عند عدم تسجيل الاطمئنان.

**السؤال الذي يجيب عنه التطبيق كل يوم:** ❤️ من يحتاج منك أن تطمئن عليه اليوم؟

**الصفحة الرئيسية:** [https://wesal-rahem.vercel.app](https://wesal-rahem.vercel.app) — كانت تعيد `404 NOT_FOUND` لأن النشر لا يحتوي `index.html`. أصبحت الصفحة العربية تُخدم من `public/`.

---

## المبادئ غير القابلة للتفاوض (مطبَّقة في الكود)

1. **وصال ليس تطبيق مراقبة** — لا قراءة رسائل، لا تسجيل مكالمات، لا تتبع موقع، لا مراقبة سرية.
2. **لا استنتاج للوفاة أو الخطر** — عدم الرد يعني فقط: `لم يتم التحقق`.
3. **الموافقة أولًا** — لا تنبيه لأي طرف ثالث قبل موافقة صريحة قابلة للإلغاء **وقبول** الجهة المدعوة.
4. **أقل قدر من البيانات** — أرقام الهواتف تُخزَّن مشفّرة (AES‑256‑GCM) مع بصمة HMAC للبحث.
5. **لا لغة تخويف** — كل النصوص في ملف واحد (`packages/shared/src/i18n/ar.ts`) بنبرة الطمأنينة.
6. **البساطة أولًا** — إضافة أول شخص في أقل من دقيقة (الاسم، صلة القرابة، الجدول فقط).
7. **التطبيق لا يحل محل الطوارئ** — إرشاد الطوارئ يُعرض عند قلق حقيقي، ولا يُستنتج تلقائيًا.

## البنية

```
wesal-rahem-/
├── packages/shared/          # العقد المشترك: الأنواع، ألوان الحالة، نصوص ar/en، تنسيق الوقت
├── apps/api/                 # NestJS 12 + TypeScript + PostgreSQL (Clean Architecture)
│   ├── src/domain/           # منطق نقي بلا اعتماديات: الجدولة، الحالات، التصعيد، القوالب
│   ├── src/application/      # حالات الاستخدام + المنافذ (Ports)
│   ├── src/infrastructure/   # TypeORM/pg، المستودعات، التشفير، JWT/OTP، الإشعارات، الهجرات
│   ├── src/presentation/     # Controllers + Guards + فلاتر الأخطاء (قيد التنفيذ)
│   └── scripts/              # migrate · seed
├── apps/mobile/              # Expo (React Native) — RTL، Cairo، فاتح/داكن (قادم)
├── tools/db/                 # تشغيل PostgreSQL حقيقي محليًا (embedded-postgres)
└── docs/                     # المعمارية، المخطط، الافتراضات، الحالة
```

**لماذا SQL صريح بدل ORM mapping؟** المخطط (ملفات SQL) هو مصدر الحقيقة الوحيد،
ونستخدم TypeORM لإدارة الاتصال والمعاملات فقط. القرار وأسبابه في `docs/ASSUMPTIONS.md`.

## التشغيل محليًا

```bash
# 1) تثبيت الاعتماديات
npm install
npm run db:install          # أدوات قاعدة البيانات المحلية

# 2) تشغيل PostgreSQL 17 حقيقي (منفذ 5433، البيانات في .pgdata/)
npm run db:up               # يبقى يعمل في الخلفية

# 3) الإعدادات
cp apps/api/.env.example apps/api/.env   # ثم ولّد الأسرار (انظر الملف)

# 4) الهجرات
npm run migrate             # تُطبَّق تلقائيًا أيضًا عند إقلاع الخادم في التطوير

# 5) الخادم
npm run api:dev             # http://localhost:4000/v1  ·  Swagger: /docs

# الاختبارات
npm run api:test            # وحدة (منطق النطاق الخالص)
npm run api:test:e2e        # تكامل ضد wesal_test (يتطلب db:up)
```

## نموذج البيانات (مختصر)

`users` · `devices` · `auth_otps` · `auth_sessions` · `privacy_settings` · `consents` ·
`families` · `family_members` · **`persons`** (كيان مركزي واحد) · `schedules` ·
`schedule_exceptions` · `schedule_entries` · `check_ins` · `communication_attempts` ·
`contact_invitations` · `trusted_contacts` · `web_check_in_links` · `escalation_rules` ·
`escalations` · `notifications` · `scheduled_jobs` · `sync_operations` · `audit_logs`

قيود مهمة تُطبَّق في القاعدة نفسها (لا في التطبيق فقط):

- `escalation_rules.rules_auto_requires_consent` — لا تصعيد تلقائي بلا موافقة سارية.
- `persons.persons_deceased_requires_reporter` — الإبلاغ يدوي ومُسجَّل باسم مُبلِّغ.
- `escalations.escalations_stage_once_per_entry` — مرحلة لا تُنفَّذ مرتين على نفس الموعد.
- `check_ins.idempotency_key UNIQUE` — المزامنة دون اتصال لا تُنشئ سجلات مكررة.
- `invitations_active_phone_uniq` — دعوة سارية واحدة لنفس الرقم (منع الإزعاج).

## الأمان والخصوصية

- تسجيل الدخول برقم الهاتف + OTP (بصمة HMAC، مقارنة آمنة ضد هجمات التوقيت، حد محاولات).
- جلسات Token‑based مع تدوير رمز التجديد، وإبطال كل الجلسات عند اكتشاف إعادة استخدام.
- تشفير الحقول الحساسة في التخزين (AES‑256‑GCM) + بصمة للبحث.
- التحقق من الصلاحيات على الخادم دائمًا، و404 بدل 403 لمنع استكشاف المعرّفات.
- سجل تدقيق لكل عملية حساسة، مع حجب أي قيمة حساسة من البيانات الوصفية.
- حواجز إقلاع في الإنتاج: رفض `OTP_DEV_MODE=true` أو الأسرار الافتراضية أو `CORS_ORIGINS=*`.
